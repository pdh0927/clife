# 강아지 이미지

이 폴더에 PNG를 넣으면 앱이 **코드로 그린 강아지 대신 이 이미지를 쓴다.**
비어 있으면 `src/dog.swift` 의 그림으로 되돌아간다 — 빈 폴더는 고장이 아니라 정상 상태다.

## 파일 이름 — 두 가지 방식

### 방식 1 · 공용 달리기 사이클 (권장, 그림 7장)

```
run-1.png  run-2.png  run-3.png  run-4.png  run-5.png  run-6.png
stand.png
```

한 벌의 달리기 사이클을 무드마다 **속도만 다르게** 돌린다. 90%를 넘으면 `stand.png`
한 장으로 멈춘다. 달리는 속도만으로 전력질주와 터덜터덜이 구분되므로, 표정을 무드별로
따로 그리지 않아도 된다.

| 무드 | 한 바퀴 | 느낌 |
|---|---|---|
| 0–50% | **0.5초** | 전력질주 |
| 50–70% | 0.85초 | 꾸준히 |
| 70–90% | 1.7초 | 터덜터덜 |
| 90%~ | — | `stand.png` 로 정지 |

### 방식 2 · 무드별 전용 프레임 (그림 많음, 표정까지 다름)

```
energetic-1.png  energetic-2.png  ...   0–50%
steady-1.png     steady-2.png     ...   50–70%
tired-1.png      tired-2.png      ...   70–90%
spent-1.png                       ...   90%~
```

이쪽이 있으면 방식 1보다 **우선한다.** 지친 강아지가 실제로 지쳐 보이는 게 느리게만
도는 것보다 낫지만, 그리는 양이 서너 배다.

두 방식 모두 1번부터 없는 번호가 나올 때까지 읽는다. **4장이든 24장이든 코드를 안
고쳐도 된다.** 한 장만 넣으면 애니메이션 없이 정지 이미지가 된다.

## 규격

| 항목 | 값 | 이유 |
|---|---|---|
| 형식 | PNG, **알파 채널 필수** | 라이트/다크 메뉴 배경 위에 얹힌다. 흰 배경이면 흰 네모가 뜬다 |
| 크기 | 가로 **최소 280px** (짧은 변 200px 이상) | 레티나에서 46pt로 그려지면 실제 92px+. 여유를 두고 줄여 쓴다 |
| 캔버스 | **모든 프레임이 동일한 크기·동일한 위치** | 프레임마다 강아지가 캔버스 안에서 움직이면 애니메이션이 떨린다 |
| 여백 | 상하좌우 약간 | 꽉 채우면 잘려 보인다 |
| 비율 | 가로세로 비슷하게 (약 4:3) | 헤더의 강아지 자리가 그 비율이다 |

**프레임 간 위치 고정이 가장 중요하다.** 각 프레임을 따로 잘라내면 강아지가
제자리에서 덜덜 떨린다. 같은 캔버스에 그려서 통째로 내보내는 편이 안전하다.

## 넣는 법

```sh
cp ~/Downloads/dog-*.png assets/dog/
./setup.sh          # 빌드 → /Applications 설치 → 실행
```

`build.sh` 가 이 폴더를 `Clife.app/Contents/Resources/dog/` 로 복사한다.

## 지금 들어있는 그림

Gemini(Nano Banana)로 생성했다. 달리기 2프레임 + 앉아 쉬는 포즈 1장.

**2장뿐인 게 부족해 보이지만 그게 요점이다.** 46pt 크기에서는 프레임 수보다 두 극단의
대비가 훨씬 중요하다 — 앞발을 모은 도약과 네 다리를 쫙 뻗은 질주가 번갈아 나오면
달리는 것으로 읽힌다. 픽셀 게임이 오래 쓴 방법이다.

첫 시도는 10프레임이었는데 발이 263px 캔버스에서 10px(3.8%)밖에 안 움직여서 버렸다.
지금은 137px(30.7%)이다. `prepare.py` 가 가공 끝에 이 수치를 찍어준다.

## 라이선스 주의

이 저장소는 **공개 MIT**다. 여기 넣은 이미지는 레포와 함께 재배포된다.
스톡 사이트에서 받은 이미지(워터마크가 있거나, 개인 사용만 허용되거나, 출처 표기가
필요한 것)는 그대로 커밋하면 안 된다. 지금 들어있는 것은 생성형 모델의 출력이라
해당하지 않지만, 교체할 때 이 기준은 그대로다.

안전한 선택지:
- 직접 그리거나 의뢰한 것
- CC0 / 퍼블릭 도메인
- 상업적 재배포가 명시적으로 허용된 라이선스를 구매한 것

애매하면 `assets/dog/` 를 `.gitignore` 에 넣고 **로컬에서만** 쓰면 된다. 앱은
그래도 동작하고, 레포를 클론한 사람은 코드로 그린 강아지를 보게 된다.
