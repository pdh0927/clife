# clife

Claude Code 플랜 사용량 한도(5시간, 주간 전체 모델, 주간 모델별)를 작은 링 게이지로 메뉴바에 보여주는 macOS 앱이다. Claude 앱 메뉴바의 사용량 팝업과 같은 API를 호출하기 때문에 숫자가 그쪽과 같다.

Anthropic 공식 제품이 아니다.
Claude Pro나 Max 구독이 있어야 뭔가 보인다.

## 기능

- **메뉴바 링 게이지와 드롭다운.** 클릭하면 한도별 사용량과 초기화까지 남은 시간이 나온다. 임계값을 넘으면 알림이 뜨고, 강아지가 지금 상태를 말해 준다.
- **바탕화면 위젯.** macOS 시스템 위젯과 같은 격자에 놓인다. 강아지가 사용량에 따라 다른 속도로 뛴다.
- **단축키 카드.** 어느 앱에서든 **⌥C**를 누르면 위젯과 같은 카드가 잠깐 떴다 사라진다. 풀스크린이라 메뉴바가 안 보일 때 쓴다. 단축키는 설정 → 단축키에서 바꾸거나 끌 수 있다 — ⌥C를 잡는 동안엔 그 키로 `ç`가 안 쳐지기 때문이다.

## 설치

```sh
git clone <this-repo> clife
cd clife
./setup.sh
```

빌드해서 `/Applications`에 넣고 실행한다. 처음 실행할 때 Gatekeeper 경고(앱을 우클릭 → 열기, 한 번만)와 키체인 접근 허용 요청(`Claude Code-credentials`, "항상 허용")이 뜬다.

자세한 동작 원리와 설계 이유는 [docs/DESIGN.md](docs/DESIGN.md)에 있다.
